# RBAC Mini Project

A Spring Boot web application with user authentication and an admin panel.
This project is a learning exercise for role-based access control (RBAC), session handling, form validation, and CRUD operations.

## Features

### User Module

- User signup with validation
- User login and logout
- Authenticated user dashboard
- Secure password storage
- Session-based authentication

### Admin Module

- Secure admin login
- View registered users
- Search users by name or email
- Create, update, and delete users
- Role-based access control for admin-only pages

## Technology Stack

- Java 25
- Spring Boot
- Spring MVC
- Spring Data JPA
- Spring Security
- Thymeleaf
- PostgreSQL
- Tailwind CSS
- Maven

## Prerequisites

- Java 25
- PostgreSQL
- Node.js and npm
- Git


## Configure environment variables

DB_URL
DB_USER_NAME
DB_PASSWORD

## Learning Goals

- Build authentication with Spring Security
- Understand session and cookie security
- Implement role-based authorization
- Use JPA with PostgreSQL
- Build server-rendered pages with Thymeleaf
- Practice validation, error handling, redirects, and CRUD operations
